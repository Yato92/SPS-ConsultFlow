# 1.3 Развитие продукта

## Три сущности развития

### 1. Продуктовая очередь

Отвечает на вопрос **«что делаем для бизнеса и пользователей»**.

- Ссылка: Weeek → проект ConsultFlow → раздел «Продукт»
- Владелец: Product Owner
- Приоритизация: RICE / MoSCoW

**Примеры задач:**

- Автоматическое формирование актов.
- Клиентский портал статуса заявки.
- Расширенная аналитика по практикам.
- Улучшение расчёта стоимости и сроков.

### 2. Техническая очередь

Отвечает на вопрос **«что делаем для качества, надёжности и производительности»**.

- Ссылка: Weeek → проект ConsultFlow → раздел «Разработка»
- Владелец: Tech Lead
- Приоритизация: по критичности и влиянию на SLA

**Примеры задач:**

- Оптимизация запросов к БД.
- Повышение покрытия тестами до 80%.
- Переход на Kubernetes.
- Усиление мониторинга и алертинга.

### 3. Операционное управление

Отвечает на вопрос **«как организуем работу команды»**.

- Доска спринта: Weeek → доска «ConsultFlow Sprint»
- Расписание дежурств: Weeek → календарь «Дежурства ConsultFlow»
- Владелец: Tech Lead + Product Owner

**Элементы:**

- двухнедельные спринты;
- планирование и ретроспектива;
- дежурства поддержки по неделям;
- релизный цикл раз в 3–4 недели.
