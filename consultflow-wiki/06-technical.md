# 2. Техническая часть

## 2.1 Программные требования

### Серверная часть

| Компонент         | Технология                  |
| ----------------- | --------------------------- |
| ОС сервера        | Ubuntu 22.04 LTS            |
| СУБД              | PostgreSQL 15               |
| Backend           | Python 3.11 + FastAPI       |
| Очередь сообщений | RabbitMQ                    |
| Кэш               | Redis 7                     |
| Контейнеризация   | Docker + Kubernetes         |
| CI/CD             | GitLab CI                   |
| Веб-сервер        | Nginx                       |
| Мониторинг        | Prometheus + Grafana + Loki |

### Клиентская часть

| Компонент               | Технология                    |
| ----------------------- | ----------------------------- |
| Frontend                | React 18 + TypeScript         |
| Сборка                  | Vite                          |
| UI-библиотека           | Ant Design                    |
| Работа с API            | Axios + React Query           |
| Поддерживаемые браузеры | Chrome, Firefox, Edge, Safari |

### Дополнительно

- Аутентификация: OAuth 2.0 + JWT
- Шифрование трафика: TLS 1.3
- Формат обмена: REST + JSON
- Документация API: OpenAPI 3.0 (Swagger)

## 2.2 Аппаратные требования

| Компонент             | Минимум    | Рекомендуется          |
| --------------------- | ---------- | ---------------------- |
| CPU                   | 4 vCPU     | 8 vCPU                 |
| RAM                   | 8 ГБ       | 16 ГБ                  |
| Диск                  | 100 ГБ SSD | 250 ГБ SSD             |
| Сеть                  | 100 Мбит/с | 1 Гбит/с               |
| Резервное копирование | ежедневно  | ежедневно + репликация |
| Отказоустойчивость    | 1 нода     | 3 ноды (кластер)       |

## 2.3 Микросервисная архитектура

| Сервис               | Назначение                                              |
| -------------------- | ------------------------------------------------------- |
| API Gateway          | Единая точка входа для клиентов, маршрутизация запросов |
| Auth Service         | Аутентификация, авторизация, выдача JWT                 |
| Order Service        | Приём, хранение и обработка заявок                      |
| Routing Service      | Маршрутизация заявок по практикам и регионам            |
| Pricing Service      | Расчёт стоимости и сроков выполнения                    |
| Document Service     | Генерация договоров, актов и сопутствующих документов   |
| Notification Service | Email, Telegram, внутренние уведомления                 |
| Analytics Service    | Сбор и агрегация KPI, отчёты                            |
| Integration Service  | Интеграции с CRM, 1С, внешними системами                |
| Audit Service        | Журнал действий пользователей и системных событий       |
