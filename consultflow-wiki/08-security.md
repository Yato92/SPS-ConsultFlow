# 2.8 Безопасность

## Меры защиты

- Аутентификация: OAuth 2.0 + JWT
- Авторизация: RBAC по ролям
- Шифрование трафика: TLS 1.3
- Шифрование данных: AES-256 в БД
- Аудит действий: журнал всех операций
- Резервное копирование: ежедневно
- Защита от SQL-инъекций и XSS
- Ограничение доступа к ПДн

## Разграничение доступа

| Роль        | Доступ          |
| ----------- | --------------- |
| Менеджер    | Заявки, клиенты |
| Консультант | Свои заказы     |
| Финансы     | Договоры, акты  |
| Юрист       | Договоры        |
| Руководство | Аналитика, KPI  |
| Админ       | Полный доступ   |

## Регуляторные требования

- 152-ФЗ «О персональных данных»
- ГОСТ Р ИСО/МЭК 27001
- Внутренний регламент ИБ компании
