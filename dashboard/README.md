# Дашборд ConsultFlow

Учебный аналитический дашборд на Dash: заказы на консалтинговые услуги, полученная оплата, расходы и финансовый результат. Данные не загружаются автоматически — CSV выбирается вручную в веб-интерфейсе.

## Требования

- Python 3.11 или новее.
- Зависимости из `requirements.txt`: Dash, pandas, Plotly.

## Запуск

Из корня репозитория (Windows PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r dashboard/requirements.txt
python dashboard/app.py
```

В Linux или macOS активация окружения: `source .venv/bin/activate`.

Откройте <http://127.0.0.1:8050> и загрузите файл `dashboard/orders.csv`. Сервер слушает только localhost; остановка — `Ctrl+C`.

## Формат CSV

Разделитель — запятая, кодировка UTF-8 (с BOM или без) либо Windows-1251, первая строка — заголовок.

| Столбец | Содержимое |
| --- | --- |
| `order_id` | уникальный номер заказа, например `CF-2025-001` |
| `created_date` | дата регистрации заявки в формате `ГГГГ-ММ-ДД` |
| `client` | название клиента |
| `practice` | направление консалтинга |
| `manager` | менеджер заказа |
| `status` | статус заказа |
| `amount` | стоимость заказа, ₽ |
| `paid_amount` | фактически полученная оплата, ₽ |
| `expenses` | учтённые расходы, ₽ |

Требования к данным:

- обязательны все девять столбцов, лишние столбцы игнорируются;
- `order_id` не повторяется;
- дата должна существовать в календаре и быть записана как `ГГГГ-ММ-ДД`;
- суммы — неотрицательные числа без пробелов и текста;
- `paid_amount` не больше `amount`.

В репозитории лежит `orders.csv` — 100 синтетических (вымышленных) заказов за 2025 год. Файл создан генератором `generate_orders.py` (seed 42) и подходит для демонстрации. Пересоздать его можно командой:

```powershell
.\.venv\Scripts\python.exe dashboard\generate_orders.py
```

## Что показывает дашборд

После загрузки CSV появляются:

- **карточки**: количество заказов, полученная оплата, расходы, финансовый результат;
- **линейный график** — оплата и расходы по месяцам регистрации заказов;
- **круговая диаграмма** — структура расходов по направлениям консалтинга;
- **столбчатый график** — финансовый результат по направлениям (отрицательные значения красные);
- **таблица заказов** — сортировка по клику на заголовок, по 10 строк на страницу, отрицательный результат выделен красным.

Фильтры «Диапазон дат регистрации заявок» и «Направление консалтинга» пересчитывают все карточки, графики и таблицу одновременно. Данные хранятся в `dcc.Store` в рамках сессии страницы; при загрузке нового файла фильтры сбрасываются на его диапазон дат.

## Правила расчёта

- Финансовый результат = `paid_amount` − `expenses`. Это упрощённый учебный показатель, а не бухгалтерская прибыль: накладные расходы и налоги не учитываются.
- Временные графики группируют заказы по месяцу `created_date`, а не по дате оплаты.
- Если после фильтрации заказов нет, карточки показывают нули, а графики и таблица — поясняющее сообщение.

## Ошибки при загрузке

Дашборд проверяет пустой файл, разделитель, обязательные столбцы, пустые значения, даты, числа, отрицательные суммы, оплату больше стоимости и повторяющиеся `order_id`. Вместо traceback выводится сообщение с номерами строк CSV. При ошибке данные предыдущего файла очищаются, а фильтры блокируются, чтобы на экране не остались устаревшие показатели. Максимальный размер файла — 5 МБ.

## Ограничения

- Все данные синтетические (вымышленные) и предназначены только для лабораторной работы.
- Нет базы данных, авторизации и сохранения загруженных файлов между сессиями.
- Приложение рассчитано на локальный запуск одним пользователем.
